Self-update (restore area)

Loads a build into the panel's dedicated restore area and reboots to apply it, in one step. The panel's own bootloader verifies and applies it. Only versions matching what's currently running are listed (same logo/language variant) — this is a single fixed-purpose area, not one of the 3 generic slots below (those can hold firmware for any other device, no restriction). Newest matching version is pre-selected; pick another to roll back or repeat a specific build instead.
